# Darker Modern for VS Code

A near-black VS Code color theme package with balanced syntax contrast and two dark variants:

- **Darker Modern** uses a `#050505` editor background with visibly separated workbench surfaces.
- **Darker Modern Black** uses a fully black editor background and deeper surrounding chrome.

After installation, open `Preferences: Color Theme` and select either variant.

The source repository also provides native Darker Modern themes for Neovim, Ghostty, Fish, tmux, Zed, and Zellij.
